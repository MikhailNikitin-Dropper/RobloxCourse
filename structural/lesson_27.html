Урок 27. Монстр и его анимации

Роль гейм-дизайнера: Character Animator

Общая длительность: 60 мин

Приветствие (1 мин)

Сегодня ты — Character Animator (1 мин)

Сегодня мы добавим в лабиринт монстра. Мы соберём его тело и научим его двигаться.

Character Animator (аниматор персонажа) собирает персонажа и создаёт ему анимации.

Заметка ведущего: Сказать: сегодня в лабиринте появится монстр — с уникальным обликом и анимациями ходьбы и атаки.

Повторение прошлого урока (4 мин)

Вспомним урок 26 (4 мин)

Зачем в лабиринте нужна хотя бы одна петля?

  1. Чтобы не помогало правило «следуй вдоль стены» ✓
  2. Чтобы сегменты коридора стыковались друг с другом
  3. Чтобы в тёмных коридорах лабиринта стало светлее

Что будет, если тупик не закрыть торцевой стенкой?

  1. Игрок застрянет в этом тупике
  2. Тупик будет выглядеть проходом ✓
  3. Сегменты развалятся при запуске

Чем в лабиринте отмечают крупную развилку?

  1. Приманкой, которая обещает игроку награду в тупике
  2. Копиями сегмента коридора, поставленными по кругу
  3. Неярким факелом уникального цвета на развилке ✓
Заметка ведущего: Спросить: три вопроса со слайда. Ответы: чтобы не помогало правило «следуй вдоль стены»; тупик будет выглядеть проходом; факелом уникального цвета. Спросить: где в вашем лабиринте спрячется монстр?

Основа, облик и первая анимация (20 мин)

Что делаем сегодня (2.5 мин)

  • Основа монстра — заготовка с готовыми суставами
  • Облик монстра — размер, цвет и самодельные детали
  • Движения — ClipEditor: зацикленная ходьба и разовая атака
  • Публикация — у каждой анимации появляется ID-номер
Заметка ведущего: Сказать: путь занятия — от готовой основы рига до двух анимаций с номерами, по которым игра их найдёт. Сказать: сегодня будет и облик, и две анимации, и публикация.

Rig Generator: основа (2.5 мин)

  • Rig Generator (генератор рига) — инструмент Studio, кнопка Character на вкладке Avatar
  • R15 — 15 подвижных частей тела, R6 — только 6: берём R15, движений больше
  • Результат — готовая Model с именем Rig: суставы уже расставлены и работают

[изображение: Панель Rig Generator открыта на вкладке Avatar, курсор наведён на кнопку Character; Explorer ещё без вставленного рига — панель показывает выбор стиля до создания]

Заметка ведущего: Показать в Studio: вкладка Avatar → Character → выбрать R15.

Риг: детали на суставах (2.5 мин)

  • Риг — это части, соединённые подвижными суставами
  • Каждый сустав соединяет две детали: одна стоит на месте, другая поворачивается от точки сустава
  • ClipEditor работает с любым ригом — не только с человекоподобным
Заметка ведущего: Сказать: тот же принцип был у колеса обозрения и у машины, просто здесь суставов много и они складываются в тело.

Детализация рига (2.5 мин)

  • Размер и материал — любой части рига меняются в Properties без риска
  • Самодельная деталь — рог, шип или коготь: готовим её отдельно от рига
  • Скрепляем сваркой: выделяем деталь декора и часть рига, потом Model → Weld — касаться друг друга им необязательно
  • Деталей несколько — складываем в одну папку (Decor) внутри рига

[изображение: Explorer: папка Decor внутри рига с несколькими деталями декора, рядом выделены деталь-рог и часть рига перед нажатием Weld]

Заметка ведущего: Сказать: декор — отдельная готовая деталь, а не переделка рига; свариваем её с частью рига, и сустав ничего не теряет. Сказать: касаться друг друга деталям не обязательно, а порядок выделения роли не играет. Сказать: цвет тела задаём только через BodyColors — обычный Color в игре сбрасывается; тем же приёмом красили Хранителя на уроке 6.

ClipEditor: поза за позой (2.5 мин)

  • ClipEditor (редактор анимаций) — вкладка Avatar, работает с выделенным ригом
  • Ключевой кадр — двигаем ползунок на нужный момент, поворачиваем или двигаем часть тела, и редактор сам создаёт ключевой кадр
  • Плавный переход — между кадрами поза плавно переходит в следующую, прорисовывать каждый миг не нужно

[изображение: Окно ClipEditor: шкала времени с несколькими ключевыми кадрами, риг застыл в промежуточной позе шага]

Заметка ведущего: Показать в Studio: вкладка Avatar → ClipEditor при выделенном риге.

Ходьба и атака (2.5 мин)

  • Looping (зацикливание) в панели воспроизведения — включаем для ходьбы, оставляем выключенным для атаки
  • Атака — короче: несколько кадров замаха и удара, без повтора
Заметка ведущего: Спросить: какое движение монстра будет повторяться, а какое — разовым? Ответы: ходьба по кругу, атака один раз. Сказать: чтобы цикл не дёргался, последний кадр ходьбы делаем копией первого.

Номер анимации (2.5 мин)

  • Publish to Roblox (опубликовать в Roblox) — пункт меню «…» в ClipEditor
  • Числовой ID — появляется у анимации после публикации
  • Номер для следующего занятия — по нему готовый модуль монстра найдёт нужную анимацию
Заметка ведущего: Сказать: публикация анимации — тот же приём, что с игрой и модулями курса: кнопка, название, номер. Сказать: записываем номер — на следующем уроке готовый скрипт монстра найдёт анимацию именно по нему.

Частые ошибки (2.5 мин)

  • Покрасили тело через обычный Color — после запуска цвет пропадает
  • Сварили деталь не с той частью рига — декор двигается не туда или остаётся на месте, когда монстр идёт
  • Забыли включить Looping у ходьбы — анимация играет один раз и замирает
  • Не скопировали первый кадр в конец — на стыке анимация ходьбы выглядит дёрганой
Заметка ведущего: Сказать: каждая из четырёх ловушек — реальная причина «монстр не двигается», «монстр развалился» или «монстр стал серым».

Вопросы по теории (4 мин)

Вопросы по теории (4 мин)

Чем отличается риг и просто набор деталей?

  1. Детали соединены суставами ✓
  2. Детали похожи на человека
  3. Есть декоративные детали

Чем анимация ходьбы отличается по настройке от анимации атаки?

  1. У атаки больше ключевых кадров
  2. У ходьбы включён Looping ✓
  3. Атаку нельзя опубликовать, только ходьбу

Нужно ли декоративной детали касаться рига, чтобы сварка сработала?

  1. Да, иначе сварка не получится
  2. Да, если детали одного размера
  3. Нет, достаточно выделить обе детали ✓
Заметка ведущего: Спросить: три вопроса со слайда. Ответы: детали соединены суставами; у ходьбы включён Looping; нет, достаточно выделить обе детали. Сказать: копия первого кадра в конце — тоже часть гладкого цикла, отдельно от Looping.

Собираем и оживляем монстра (20 мин)

Шаг 1: место для монстра (1.5 мин)

  1. Открой плейс лабиринта
  2. Выбери развилку или комнату, где будет находиться монстр
  3. Запомни координаты места: сюда встанет риг
Заметка ведущего: Сделать: открыть плейс лабиринта урока 26. Спросить: где будет находиться монстр — на развилке или в комнате, которую называли в начале урока? Сказать: запомнить координаты выбранного места — сюда встанет риг.

Шаг 2: вставляем риг (3 мин)

  1. Avatar → Character → выбери R15
  2. Переименуй вставленную Model «Rig» → например, Monster
  3. Перетащи модель на выбранное в шаге 1 место

[изображение: Explorer: Model Monster (бывший Rig) стоит на нужном месте лабиринта, дерево частей раскрыто]

Заметка ведущего: Показать в Studio: Avatar → Character → R15, переименовать Model из «Rig» в Monster и перетащить на выбранное место. Сказать: риг встаёт у камеры, а не в лабиринте, — переносим его сразу, мышью или через Position.

Шаг 3: облик монстра (2.5 мин)

  1. Найди BodyColors у рига и задай цвета — HeadColor3, TorsoColor3, LeftArmColor3 и так далее
  2. У отдельных частей поменяй Size или Material в Properties — по вкусу
  3. Суставы не трогай — меняются только BodyColors и свойства самих частей

[изображение: Панель Properties объекта BodyColors: подсвечены поля HeadColor3, TorsoColor3, LeftArmColor3 с заданными цветами]

Заметка ведущего: Показать в Studio: BodyColors у рига (или «+» → BodyColors) — HeadColor3, TorsoColor3, LeftArmColor3 и остальные. Сказать: Size и Material можно менять прямо у частей в Properties. Проверить у каждого: суставы не тронуты — это самый безопасный слой правок.

Шаг 4: рога или шипы (3 мин)

  1. Возьми или создай небольшую декоративную деталь (рог, шип, коготь)
  2. Помести её рядом с нужной частью рига — вплотную необязательно
  3. Выдели деталь декора и нужную часть рига, потом Model → Weld — порядок выделения не важен
  4. Добавляешь не одну деталь, а несколько — сложи их в отдельную папку (например, Decor) внутри рига
Заметка ведущего: Сказать: форму и размер детали декора настраиваем в Properties. Показать в Studio: выделить деталь-рог, затем с Ctrl — нужную часть рига, и нажать Weld на вкладке Model. Сказать: кто уверенно работает с Tabby с урока 6 — может одеть рига нарядом вместо рогов и шипов.

Шаг 5: анимация ходьбы (5.5 мин)

  1. Выдели рига целиком, открой ClipEditor
  2. Поставь 4–6 ключевых кадров на анимацию длиной около 1 секунды: нейтральная поза → шаг левой ногой → нейтральная → шаг правой ногой
  3. Скопируй первый кадр и вставь копию в конец шкалы — включи Looping

[изображение: Галерея: ClipEditor с реальной анимацией «Monster Walk» в трёх позах ходьбы (нейтральная, шаг левой ногой, шаг правой ногой), кнопка Looping включена (подсвечена)]

Заметка ведущего: Сказать: это первая анимация в жизни группы — не торопим. Если позу плохо видно в темноте: на время работы поднять Brightness или ClockTime, а после публикации вернуть исходные значения.

Шаг 6: атака, публикация, номер (4.5 мин)

  1. Создай вторую анимацию длиной около 0.5–0.8 секунды — замах и удар, без Looping
  2. Опубликуй обе анимации (Publish to Roblox) — запиши номера
  3. Сохрани оба номера: на следующем уроке их будет использовать монстр; найти их снова можно на сайте Roblox, в разделе Creations

[изображение: Галерея: 1) готовая анимация атаки с ключевыми кадрами в ClipEditor; 2) меню «…» с пунктом Publish to Roblox; 3) диалог Asset Configuration с названием анимации и кнопкой Save]

Заметка ведущего: Показать в Studio: меню «…» в ClipEditor → Publish to Roblox — после публикации появится номер анимации. Сказать: номера пока только записываем — на следующем уроке их будет использовать монстр: впишем номера в атрибуты папки модуля.

Вопросы по практике (4 мин)

Вопросы по практике (4 мин)

Почему цвет тела монстра задавали через BodyColors, а не через Color?

  1. Color сбрасывается при запуске игры ✓
  2. Color нельзя менять у частей рига
  3. BodyColors красит только голову рига

Почему для атаки не включили Looping?

  1. Looping недоступен для коротких анимаций
  2. Publish не пропускает зацикленные анимации
  3. Атака должна сыграть один раз ✓

Откуда берётся номер анимации для монстра?

  1. Из имени модели монстра в Explorer
  2. Из публикации анимации в ClipEditor ✓
  3. Из свойства BodyColors у рига
Заметка ведущего: Спросить: три вопроса со слайда. Ответы: Color сбрасывается при запуске игры; атака должна сыграть один раз; из публикации анимации в ClipEditor. Спросить: что, по-вашему, скрипт монстра сделает с этими номерами на следующем уроке?

Монстр лабиринта готов (2 мин)

Сегодня мы собрали монстра лабиринта: облик, походку и атаку.

  • Сохрани проект в конце занятия: File → Save to Roblox

Заметка ведущего: Сказать: на следующем уроке номера пригодятся модулю монстра, и ночной лабиринт станет полноценной игрой. Сделать: File → Save to Roblox — иначе вместе с плейсом потеряется и риг.
